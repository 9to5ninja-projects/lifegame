# 🗺️ MORTALITY LOTTERY - DEVELOPMENT ROADMAP

## ✅ COMPLETED (v1.0) - October 2025

### Core Mechanics
- [x] Birth card system (15 regions, weighted by population)
- [x] Family structure cards (12 types)
- [x] Event system (50+ cards across childhood/teen/adult)
- [x] Death system (30 causes, age-stratified)
- [x] Survival % stat with yearly death checks
- [x] Resources & Agency stats
- [x] Profile tag system for card compatibility

### Scoring & Progression
- [x] Difficulty multipliers (1x-5x based on birth)
- [x] Milestone bonuses (age 18, 60, 80)
- [x] **Life expectancy tracking** (real-world data per region)
- [x] **Life expectancy bonus** (+10 pts/year over expectancy)
- [x] **Voluntary fold mechanic** (quit anytime, -30% penalty)

### UI & Playability
- [x] Standalone HTML version (no build tools required)
- [x] React component version
- [x] Death screen with life summary
- [x] Event log with history
- [x] Auto-play mode
- [x] Dark theme UI

### Documentation
- [x] Complete README with game mechanics
- [x] Quick start guide
- [x] What's new changelog
- [x] Card templates for expansion
- [x] Simulation script for balance testing

## 🎮 PHASE 5: MULTIPLAYER (Target: Q1 2026)

### Simultaneous Lives (Priority: HIGH)
- [ ] 2-4 players start at birth
- [ ] Turns happen simultaneously
- [ ] Race to highest score or longest life
- [ ] Death eliminates player but they can spectate
- [ ] Winner declared when all die or reach age 100

### Draft Mode (Priority: MEDIUM)
- [ ] Players draft birth cards from a pool
- [ ] Snake draft order
- [ ] Strategic choice: high-resource safe or low-resource high-multiplier?
- [ ] Family cards drafted second

### Interaction Mechanics (Priority: LOW)

- [ ] Gift agency points
- [ ] "Help" actions (increase another's survival %)
- [ ] "Sabotage" actions (decrease another's survival %)
- [ ] Alliance system (share resources, protect each other)

### Spectator Mode (Priority: LOW)

## 🎯 VISION STATEMENT

**We're building the game that:**
- Makes you say "holy shit" when you die at age 2
- Makes you feel accomplished when you survive to 80 in a war zone
- Makes you immediately hit "play again" after every death
- Teaches you about global inequality without feeling preachy
- Goes viral because everyone wants to share their crazy life story

**This is Cards Against Humanity meets Oregon Trail meets WHO Statistics.**

**Dark. Educational. Addictive. Viral.**
